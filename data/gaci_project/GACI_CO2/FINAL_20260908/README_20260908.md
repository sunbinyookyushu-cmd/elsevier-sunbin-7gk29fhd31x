## What changed on 8 September (data-accuracy rebuild)
1. **Airport -> country assignment fixed** (`_iso_map.py`, used by 01 and 06). The old crosswalk lacked ISO2 codes for Taiwan, Reunion, Guadeloupe, Martinique, Mayotte, Jersey, Guernsey, Cook Islands, Western Sahara and others, and OurAirports lacks several closed or renamed airports. Airports that were silently dropped from national totals included Bishkek Manas (KGZ, the country's main airport: national CO2 was understated by two thirds), Tripoli (LBY, 1996-2018), Ganja (AZE), Oslo Fornebu (NOR), Kyiv Zhuliany and Donetsk (UKR), Murcia San Javier (ESP), Campinas (BRA), Tel Aviv Sde Dov and old Eilat (ISR). Unassigned emissions fall from 1.2 percent to 0.02 percent; world 2023 aviation CO2 is 848 Mt (was 838).
2. **Eswatini restored** in the spatial, spillover and placebo samples (coordinate file used the old name "Swaziland"); singleton country (New Caledonia) dropped in the Python spatial models as in Stata, so every table uses N = 4,634.
3. **1996 baseline geography recovered for the 34 countries entering the panel after 1996** (placebo, rival-cycle and alternative-shifter tests now run on the full sample instead of 4,121 country-years).
4. All Stata do-files and Python builders rerun; every table swapped in and every number in the prose, captions and notes recomputed from the result CSVs (`38_rebuild_tex_20260908.py`, 78 replacements, zero failures).
5. Editorial fixes from the 8 September review: Table 1 intensity column removed (reported in Table 2); Extended Data Table 1 Panels D-E removed; SAF growth-rate unit; Supplementary Table 1 robust row; ED Fig 1 regenerated with clustered CIs; captions of ED Figs 6, 9, 10; attribution shares on one denominator (world 2023 = 848 Mt); mismatch wording (stage length, not international orientation); Methods clauses on the stress-test sample and the tourism-instrument p-values.
